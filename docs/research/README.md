# Research repository

This is where research findings live once they're synthesised. Raw recordings and personal data **do not** go in this repo, because it is public and POPIA applies (see below).

## Structure
```
docs/research/<project>/
  plan.md        research questions, method, participants, timeline
  log.md         sessions run: anonymised ID (P1, P2…), date, method
  insights.md    insight headline · evidence (quotes, frequency "4 of 6") · so-what
  desk/          secondary research with source links and the tier from docs/sources.md
```

## Rules
- **Anonymise everything here.** Use P1, P2 and so on, with no names, emails, employers or faces. Quotes must not identify the speaker.
- Consent forms, recordings and contact details stay **off-repo** in a private folder.
- Every insight shows its evidence and frequency. "Users want X" with no count is not an insight.
- Mark desk research claims with their source tier.
