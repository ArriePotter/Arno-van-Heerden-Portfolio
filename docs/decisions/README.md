# Decision log

This is a lightweight version of the Architecture Decision Records (ADRs) that engineering teams use, applied to design. Each file records one decision: the context, the options considered, the choice, the evidence and the consequences.

**Why:** "Why did you do it this way?" is the most common question in a portfolio review. These records answer it with dated, sourced reasoning instead of after-the-fact stories.

**How:**

- Copy `0000-template.md` to `NNNN-short-title.md`, using the next number.
- Write the record **when the decision is made**.
- Never edit an accepted decision's reasoning. To change course, write a new record and mark the old one `Superseded by NNNN`.
